# TH06 语言适配

TH06 的语言准备沿用 thcrap 的有限格式语义，代码保留本作渲染、字体、sprite 和 ANM 常量。移植到其他作品时复用边界，不复制本作数值。

原作日文/关闭翻译是独立回归路径。无效或缺失翻译回退到本作原始资源；不得隐式读取另一作品的字体缓存或运行内存。Host 编译静态包，游戏不持有任意上游网络地址。

文字栅格化不仅是字体文件选择，还涉及 GDI 行高、宽度、字距和裁剪。Shift-JIS 解码、UTF-8 编码和显示宽度分别处理；拷贝不得截断 UTF-8，资源中的格式串不得作为 printf 的格式参数。纹理、临时表面和复制矩形都要满足实际文字宽度。

图文 atlas 与 sprite 矩阵按本作所有者维护。对话等待、自动推进、符卡/Bomb 文本和 Music Room 描述分别验证；改变文字长度时检查表面、布局和绘制消费者，不能只改一个宽度常量。

`src/` 中的本作适配和主项目 `integrations/thcrap.mjs`、静态语言准备器构成完整链路。测试应覆盖原作回退、真实翻译、缺字/长文本、对话输入、音乐选择及运行重载，不用源 token 数量判断支持。
